# NOVA — Frontend Portfolio Project

React + Vite portfolio project prepared for GitHub mobile upload.

All source files are intentionally at the repository root so GitHub's mobile
uploader cannot flatten nested `src/components` folders and break Vercel builds.

## Vercel settings
- Framework Preset: Vite
- Root Directory: ./
- Build Command: npm run build
- Output Directory: dist
- Install Command: npm install

## Local
npm install
npm run dev
